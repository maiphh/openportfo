Each student is required to record themselves presenting and demonstrating their completed application.

Your video demo should focus on the following:

Project idea and application purpose
User interface and main application functionality
System architecture and explanation of how the components interact
AWS services actually implemented in the application
Clear evidence that AWS services are automatically invoked by the application
Justification for the selected technologies and AWS services
Third-party APIs, if used
Deployment and an end-to-end demonstration of the application
Your understanding and knowledge of the tools and technologies used
You are not required to present your report in the video. However, you must explain your system architecture as part of the demonstration.

The video should focus primarily on the actual working application. Simply showing AWS services configured in the AWS Management Console is not sufficient. You should clearly demonstrate how the services are integrated into your application and automatically invoked through the application.

The video demo must not exceed 15 minutes.
