## 1. Problem restatement

SA design `docs/orchestration/designs/BL-027-portfolio-csv-export-design.md` (complex=true) blocks on three choices: whether `GET /api/portfolio/export?format=csv` should return inline `text/csv` from Beanstalk or stage an S3 object and return a presigned URL when the demo rubric rewards S3 (Storage) evidence under a ≤$50 budget with locked stack (Beanstalk FastAPI t3.micro, S3+CloudFront frontend, no API GW, no SSR, Cognito JWT, cache-first pricing, stored FX only); how to expose presigned generation behind the thin-wrapper `ObjectStorage` port without leaking `boto3` to services; and which Python CSV pattern keeps `services/` pure, testable, Excel-compatible (line endings, quoting, BOM, 2dp, FX headers) and injection-safe for ≤100 holdings.

Detail: Q2 port pattern options within Option C:

- **C1 (recommended if C chosen):** `ObjectStorage.generate_presigned_url(key: str, expires_in: int, content_disposition: str, content_type: str = "text/csv") -> str` — adapter builds `s3.generate_presigned_url('get_object', Params={'Bucket': bucket, 'Key': key, 'ResponseContentDisposition': content_disposition, 'ResponseContentType': content_type}, ExpiresIn=expires_in)`.
- **C2:** `put_bytes(key, data: bytes, content_type)` + `presign_get(key, ...)` split — more flexible but two port methods vs one.

Q3 Python CSV idioms (apply to all options, pure service):

- **Writer:** `csv.writer(StringIO, dialect='excel', lineterminator="\r\n", quoting=csv.QUOTE_MINIMAL, doublequote=True, quotechar='"')` — RFC 4180 + Excel compat. Source: dialect defaults verified in [Python csv](https://docs.python.org/3/library/csv.html) and `excel` dialect definition.
- **Encoding:** HTTP body `text/csv; charset=utf-8` via `Response(..., media_type="text/csv; charset=utf-8")`. For file download with Excel double-click garble, **optionally** prepend BOM `\ufeff` or serve `utf-8-sig` — but design §3.1 mandates `charset=utf-8` without BOM; BOM adds invisible `\ufeff` to first header for non-Excel consumers ([Python csv](https://docs.python.org/3/library/csv.html) notes on BOM handling).
- **Decimals:** Quantize to 2dp with `Decimal.quantize(Decimal("0.01"))` or `format(d, ".2f")` consistent with BL-012; never `str(float)` (binary drift). Totals already `Decimal`.
- **Headers:** `X-FX-Status: fresh|missing|stale_ok` + `X-FX-As-Of` (ISO) matches portfolio FX contract; CSV column `fxStatus` duplicates for offline use (AC3).
- **Injection:** Sanitize user-controlled `note`/`symbol` at export time only: if `cell.lstrip().startswith(('=','+','-','@','\t','\r'))` or full-width `＝＋－＠`, prefix `'` (OWASP single-quote) or `"\t"` tab-inside-quoted-field Excel-resistant variant; always rely on `csv.writer` quoting (`QUOTE_MINIMAL` quotes delimiter/quotechar/CRLF) — never hand `','.join`. Sources: [OWASP CSV Injection](https://owasp.org/www-community/attacks/CSV_Injection), [WSTG INPV-21](https://owasp.org/www-project-web-security-testing-guide/latest/4-Web_Application_Security_Testing/07-Input_Validation_Testing/21-Testing_for_CSV_Injection).

## 4. Tradeoff analysis

- For OpenPortfo constraints (≤$50, Beanstalk+S3+Lambda, no API GW, no SSR):
  - **Budget & locked stack:** MVP hard cap `docs/prd/OpenPortfo_PRD.md#5.6` and `docs/architecture-design.md#8` target ~$0–15/mo (t3.micro single instance, DynamoDB on-demand, <5 GB S3, Athena MB scans). Inline A adds $0; S3 presigned C adds ~$0.02/mo at demo scale — both under $50, but A preserves budget headroom with zero IAM/lifecycle drift. Rubric Storage (3 pts: `architecture-design.md#3.3` — S3 3, DynamoDB 3, CloudFront 3, Athena 3, Beanstalk 6, Lambda 6) is **already satisfied** by `S3` frontend bucket + `s3://{DATA_BUCKET}/snapshots|history` snapshot/history path (`architecture-design.md#3.0`, `#4.3`, `backend/app/adapters/s3/storage.py`). S3 presigned CSV is a *second* Storage proof, not a requirement for the 3-pt S3 mark; sacrificing simplicity for an additive mark is poor under ≤$50 when the existing S3+Athena story plus cache-first pricing (FR-P3/P9/P10) already narrates Storage + Database + Analytics.
  - **Latency & Beanstalk t3.micro:** ≤100 holdings render in <3 s NFR1 when cache warm; CSV serialization of ≤100 lines is <1 ms. Inline TTFB = API latency only. Presigned adds sequential `PutObject` (~10–25 KB) then signing (local, free — [boto3 presigned](https://docs.aws.amazon.com/boto3/latest/guide/s3-presigned-urls.html) notes "Generate a presigned URL" is client-side, no network call) plus browser's second fetch to S3 — at least one extra hop and CORS preflight if cross-origin. EC2 instance-profile credentials rotate ≤6 h ([S3 presigned docs](https://docs.aws.amazon.com/AmazonS3/latest/userguide/using-presigned-url.html) — "IAM role credentials used by EC2 instances — valid for duration of role credentials (typically 6 hours)") so `ExpiresIn` >3600 s is silently capped; inline has no expiry/rotation concern.
  - **Testability & thin-wrapper rule:** Inline pure `ExportService` is testable with `InMemoryHoldingsRepo` / `InMemoryPriceCacheRepo` / `InMemoryExchangeRateRepo` and `TestClient` asserting `Content-Type: text/csv; charset=utf-8`, `Content-Disposition: attachment; filename="openportfo-portfolio-YYYYMMDD.csv"`, `X-FX-Status`, row math vs `PortfolioView` — no `boto3` mock. Presigned forces stubbing `generate_presigned_url` and either mocking S3 or treating presigned URL as opaque string in unit tests; D3's `grep -R "boto3\|botocore" backend/app/services backend/app/api backend/app/domain` gate must still pass by confining `boto3` to `backend/app/adapters/s3/storage.py:12-72` (current port `get_json/put_json/list_keys/ping` only — `storage.py:8-25`). Adding C mutates the port and adapter and widens review surface.
  - **Security surface:** Inline has no bearer URL; presigned URLs are bearer tokens — anyone with the URL can GET until expiry ([S3 presigned docs](https://docs.aws.amazon.com/AmazonS3/latest/userguide/using-presigned-url.html) — "capabilities ... limited by permissions of user who created it" and "protect them appropriately"). Mitigations from [securing presigned blog](https://aws.amazon.com/blogs/compute/securing-amazon-s3-presigned-urls-for-serverless-applications/) — least-privilege per-prefix (`s3:GetObject`/`s3:PutObject` scoped to `arn:aws:s3:::DATA_BUCKET/exports/${cognito:sub}/*`), `s3v4` + `virtual` addressing, `ResponseContentDisposition: attachment; filename="..."` signed into URL, short `ExpiresIn 300s`, bucket policy `s3:signatureAge >600s deny`, optional UUID key — are sound but additive.
  - **CSV correctness:** For ≤100 rows, `Response(StringIO.getvalue())` and `StreamingResponse(generator)` produce byte-identical output; streaming's win (memory O(batch) via `yield_per`) only matters at 10k+ rows/history exports. Per [Python csv](https://docs.python.org/3/library/csv.html), default `excel` dialect already uses `lineterminator="\r\n"` and `QUOTE_MINIMAL`; explicitly setting them makes intent clear and survives `unix` env differences. `utf-8` without BOM matches API spec; Excel double-click users may need BOM — tradeoff documented as open question. 2dp quantization and `X-FX-Status` keep parity with `GET /portfolio` (`fx_math.py:108-114`, `currency_service.py:133`).

## 5. Recommendation

**Recommended:** Option **A — Inline `text/csv` via `csv.writer` + `io.StringIO` + `Response`** as the locked default for BL-027. **Keep Option C (S3 presigned) as a documented opt-in extension** gated by a query flag (`?delivery=inline|presigned`), not the default.

**Rationale:**

- **Budget & rubric:** Inline is $0 and satisfies ≤$50 while existing S3 (frontend + snapshots/history) already proves Storage marks (`architecture-design.md#3.3`); S3 presigned CSV adds only a second Storage proof for negligible marks at extra IAM/lifecycle cost — Cited: [S3 pricing](https://aws.amazon.com/s3/pricing/) — PUT $0.005/1k, GET $0.0004/1k, free presigned generation; [S3 presigned docs](https://docs.aws.amazon.com/AmazonS3/latest/userguide/using-presigned-url.html) — presigned generation is credential-based SigV4 signing, not a billed request.
- **Latency & simplicity for ≤100 holdings:** No S3 PUT before response; TTFB minimal on t3.micro; pure service testable offline — Cited: [boto3 presigned](https://docs.aws.amazon.com/boto3/latest/guide/s3-presigned-urls.html) — `generate_presigned_url('get_object', Params={Bucket, Key, ResponseContentDisposition}, ExpiresIn=...)` is local; inline avoids its extra hop.
- **Locked decisions preserved:** No `DATA_BUCKET` required, no API GW, no SSR, no `boto3` outside `adapters/`, FX stays stored-only (`FxService.get_context()`), cache-first — matches `BL-027 design` D1 default inline unless Research justifies otherwise.
- **CSV idioms align with standards:** `lineterminator="\r\n"`, `QUOTE_MINIMAL`, `utf-8`, `X-FX-Status`/`X-FX-As-Of`, 2dp `Decimal` — Cited: [Python csv](https://docs.python.org/3/library/csv.html) — dialect params + `excel` defaults; [FastAPI custom response](https://fastapi.tiangolo.com/advanced/custom-response/) — `Response(content, media_type, headers)` sets `Content-Type`/`Content-Length` automatically; [OWASP CSV Injection](https://owasp.org/www-community/attacks/CSV_Injection) + [WSTG INPV-21](https://owasp.org/www-project-web-security-testing-guide/latest/4-Web_Application_Security_Testing/07-Input_Validation_Testing/21-Testing_for_CSV_Injection) — formula-triggering chars `= + - @ \t \r \n` + full-width variants, Excel-resistant `"\t=..."` vs `"'"` prefix.
- **S3 path retained correctly:** If SA later needs stronger Storage evidence, add C behind flag without breaking inline contract — adapter change isolated to `backend/app/adapters/s3/storage.py` via `Config(signature_version='s3v4', s3={'addressing_style':'virtual'})` as per [boto3 presigned](https://docs.aws.amazon.com/boto3/latest/guide/s3-presigned-urls.html).

## 6. What SA should lock

- **Decision to put in SA design D1:** **Lock inline `text/csv` as canonical `GET /api/portfolio/export?format=csv` response** (`200 text/csv; charset=utf-8`, `Content-Disposition: attachment; filename="openportfo-portfolio-YYYYMMDD.csv"`, `X-FX-Status`, `X-FX-As-Of`). Document S3 presigned as **future opt-in** (`?delivery=presigned` or `Accept: application/json` wrapper) — not default. Update `docs/orchestration/designs/BL-027-portfolio-csv-export-design.md#3.1` and D1 consequence to state rubric tradeoff explicitly.
- **API / adapter choice:**
  - API: `backend/app/api/portfolio.py` adds single handler following `get_portfolio:128` pattern — `get_current_user`, `resolve_currency`, `fxService.get_context()`, `portfolioService.get_portfolio(user_id, display_currency, fx_context=...)`, `ExportService.render_csv(view)` → `Response`. Keep `StreamingResponse` generator code as an internal helper (or comment) for future large exports, but ship `Response` for ≤100.
  - Domain service: `backend/app/services/export_service.py` — `def render_csv(view: PortfolioView) -> str` pure function using `csv.writer(StringIO, lineterminator="\r\n", quoting=csv.QUOTE_MINIMAL)`; money via `quantize(Decimal("0.01"))`; blank converted cols when `FxContext.rate(src,dst) is None`; CSV injection sanitize at row-write time (`'=`/`+`/`-`/`@` prefix `'`).
  - Port: **Do not extend `ObjectStorage` now.** If presigned later adopted, add (C1) `generate_presigned_url(key, expires_in=300, content_disposition, content_type="text/csv") -> str` and optional `put_bytes(key, data: bytes, content_type)` to `backend/app/ports/storage.py:8-25`; keep `boto3` confined to `backend/app/adapters/s3/storage.py:12-72` with `boto3.client('s3', config=Config(signature_version='s3v4', s3={'addressing_style':'virtual'}))` and `Params={'Bucket': bucket, 'Key': key, 'ResponseContentDisposition': content_disposition, 'ResponseContentType': content_type}`. Provide `InMemoryObjectStorage` stub returning `f"https://fake-s3/{bucket}/{key}?expires={expires_in}&sig=fake"` for tests.
  - Frontend: `frontend/lib/portfolio.ts: exportPortfolioCsv()` fetches `text/csv` → `Blob` → `URL.createObjectURL` → `a[download]` click; no S3 redirect handling in MVP.
- **Config / infra impact:**
  - **Inline default:** No new env (`DATA_BUCKET` not required), no bucket CORS, no IAM change, no lifecycle. Beanstalk role unchanged.
  - **Presigned opt-in (if later enabled):** Reuse `DATA_BUCKET` (no new bucket); add Beanstalk instance-profile policy `s3:PutObject` + `s3:GetObject` scoped to `arn:aws:s3:::DATA_BUCKET/exports/${userId}/*` (least-privilege per [securing presigned blog](https://aws.amazon.com/blogs/compute/securing-amazon-s3-presigned-urls-for-serverless-applications/)); bucket policy `s3:signatureAge` 600s deny; CORS `GET` from CloudFront origin; lifecycle `Expiration: 7d` on `exports/*`; presigned `ExpiresIn 300s` (max 7d for IAM user, ≤6h for EC2 role — [S3 presigned docs](https://docs.aws.amazon.com/AmazonS3/latest/userguide/using-presigned-url.html)).
- **Risk if recommendation ignored (i.e., defaulting to presigned):** Extra PUT latency harms NFR1 p95 <3s on t3.micro; bearer-URL leakage risk; expiry vs credential-rotation confusion (EC2 role mid-demo expiry); audit finding `boto3` in services if wrapper mis-placed; marginal Storage marks gain does not offset added operational debt under ≤$50. Mitigate by keeping inline canonical and presigned additive.

## 7. Open questions (if any)

- **Excel BOM:** Spec mandates `charset=utf-8` without BOM, but Excel Windows double-click historically mangles `utf-8` without BOM. Should `render_csv` optionally support `?bom=1` returning `utf-8-sig` (BOM) for Excel-friendly download? Recommend documenting as follow-up, defaulting to no BOM for API consumers.
- **Streaming threshold:** At what row count should handler auto-switch to `StreamingResponse` generator? Proposal: keep `Response` for MVP (≤100), note that swapping to generator is a one-line change (`return StreamingResponse(iter_csv(view), media_type="text/csv")`) when `holdings > 1000` or history export is added.
- **Presigned acceptance test:** If presigned opt-in is later enabled, verify with `curl -v <presigned_url>` that `Content-Disposition: attachment; filename="..."` is honored and `GET` succeeds within 300s, and that `ExpiredToken` path is handled (regenerate, not 500).
